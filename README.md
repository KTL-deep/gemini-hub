# 🌐 Gemini Cloud Browser (Польша -> Россия)

Готовое решение для запуска **облачного браузера в Польше** с доступом из России. 
Позволяет пользоваться оригинальным веб-сайтом **`gemini.google.com`** и вашей подпиской **Gemini Advanced** без ограничений API, блокировок и сбоев авторизации.

---

## 🌟 Как это работает

1. На сервере в Польше в Docker поднимается изолированный контейнер Chromium с движком **KasmVNC**.
2. Браузер автоматически открывает `https://gemini.google.com`.
3. Все файлы профиля, авторизация в Google и cookie сохраняются в папку `./browser-profile`. Вы входите в аккаунт **один раз**, и сессия сохраняется навсегда.
4. Вы заходите из России через любой браузер на свой защищенный сайт (`https://gemini.yourdomain.com`), вводите пароль и работаете с оригинальным Gemini.

---

## 🛠 Содержимое проекта

- [`docker-compose.yml`](file:///C:/gemini-hub/docker-compose.yml) — Конфигурация контейнера Chromium (KasmVNC) с выделенной памятью и автостартом Gemini.
- [`nginx.conf`](file:///C:/gemini-hub/nginx.conf) — Конфигурация обратного прокси-сервера Nginx с поддержкой WebSockets для плавной передачи картинки и звука.
- [`setup.sh`](file:///C:/gemini-hub/setup.sh) — Скрипт автоматической установки Docker, зависимостей, генерации пароля и запуска.

---

## 🚀 Быстрая установка на сервере в Польше

### Шаг 1. Перенос файлов на сервер
Загрузите содержимое этой директории на ваш сервер в Польше (через `git clone`, `scp` или SFTP):

```bash
git clone <ваш-репозиторий> /opt/gemini-hub
cd /opt/gemini-hub
```

### Шаг 2. Запуск скрипта автоматической установки
Сделайте скрипт исполняемым и запустите его под `root`:

```bash
chmod +x setup.sh
sudo ./setup.sh
```

*Скрипт сам установит Docker, сгенерирует случайный надежный пароль и запустит браузер.*

## 🔐 Настройка Nginx и SSL (HTTPS)

Для безопасного подключения из РФ настройте Nginx и бесплатный SSL-сертификат Let's Encrypt:

1. **Скопируйте конфигурационный файл Nginx:**
   ```bash
   sudo cp nginx.conf /etc/nginx/sites-available/gemini
   ```

2. **Отредактируйте файл и укажите ваш домен вместо `YOUR_DOMAIN.COM`:**
   ```bash
   sudo nano /etc/nginx/sites-available/gemini
   ```

3. **Активируйте сайт и перезапустите Nginx:**
   ```bash
   sudo ln -s /etc/nginx/sites-available/gemini /etc/nginx/sites-enabled/
   sudo nginx -t
   sudo systemctl reload nginx
   ```

4. **Получите бесплатный SSL-сертификат (Certbot):**
   ```bash
   sudo certbot --nginx -d ваш_домен.com
   ```

## 💡 Как пользоваться Gemini через ваш облачный браузер

1. Откройте `https://ваш_домен.com` в вашем браузере на ПК или телефоне.
2. Введите имя пользователя `admin` и пароль (выведен скриптом `setup.sh` или указан в [`docker-compose.yml`](file:///C:/gemini-hub/docker-compose.yml)).
3. В открывшемся окне облачного браузера авторизуйтесь под своим аккаунтом Google с подпиской Gemini Advanced.
4. **Готово!** Теперь у вас есть 100% функционал Gemini Advanced прямо из Польши.

## 📋 Полезные функции KasmVNC

- **Буфер обмена (Copy/Paste):** На боковой панели KasmVNC есть иконка буфера обмена для удобного переноса текста и кода между вашим ПК и облачным Gemini.
- **Масштабирование:** Браузер автоматически подстраивается под разрешение экрана вашего устройства.
- **Поддержка звука:** Можно слушать голосовые ответы Gemini Live.
